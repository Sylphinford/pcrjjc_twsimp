# account 目录

只放台服的 playerprefs xml，插件启动时会自动解析成登录账号。

把手机里的

```
/data/data/tw.sonet.princessconnect/shared_prefs/tw.sonet.princessconnect.v2.playerprefs.xml
```

复制到本目录即可，多个账号就重命名成不同的文件名（后缀保持 `.xml`）。

建议台一（美食殿堂）和台二/三/四各准备一个，台一与其他服分别走不同的登录账号，
缺失哪一边，那一边的 uid 就无法查询。仅支持新版 xml。

> 这两个文件等同于账号密码，**不要提交到 git、不要外发**，`.gitignore` 已忽略本目录下的 xml。

## 放进去了却识别不到？

在插件目录下运行自检脚本，它会直接告诉你是哪个环节的问题：

```bash
python check_account.py
```

正常输出长这样：

```
  找到 2 个 xml：

  · tw_main.xml
      [√] viewer_id = 1234567890   区服：台一·美食殿堂
  · tw_alt.xml
      [√] viewer_id = 2345678901   区服：台二·真步真步王国

结果：2 个账号可用
  台一与台其他都有账号，配置完整。
```

常见报错与原因：

| 输出 | 原因 |
|---|---|
| `没有找到 .xml 文件` | 文件放错目录，或扩展名变成了 `.xml.txt` |
| `缺少字段 [...]`，解析到的字段为空 | 不是 playerprefs.xml，或被截断/改写过 |
| `viewer_id 首段不是 1-4` | 文件不是台服账号（uid 应为 10 位） |
| 没有台二/三/四账号 | 运行时会提示「未绑定台其他服务器的查询账户」 |

改完文件要**重启 bot**，账号表只在启动时重建。
